# MemAI GitHub Vault

AI-powered second brain inspired by Mem.ai.

## Planned Features
- AI chat over notes
- GitHub-backed file storage
- Markdown editor
- Semantic search
- Tags and collections
- AI summaries
- File uploads and previews
- Responsive dashboard

## Tech Stack
Frontend: React + Vite
Backend: Node.js + Express
Storage: GitHub Repository
AI: OpenAI API

## Project Structure
- /src → frontend
- /server → backend APIs
- /data → synced markdown/json notes
